## Limits

A missing provider year/runtime does not establish a different film when independent cast/director/title evidence identifies the work. A single identity can have conflicting festival, production or distribution years. Preserve source values and review year provenance separately. The Man I Love rights-holder page currently lists 97 minutes while schedule/provider give 95; this is a metadata discrepancy, not an identity conflict.
